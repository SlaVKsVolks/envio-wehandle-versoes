# Envio WeHandle — versões

Pacotes prontos do **Envio WeHandle**, o app da Tripoloni Construtora que envia ao WeHandle os documentos dos
funcionários. Uso interno.

- **Instalar pela primeira vez:** baixe o `EnvioWeHandle-<versão>.zip` e o guia de instalação da
  [versão mais recente](https://github.com/ricardotripoloni/envio-wehandle-versoes/releases/latest) e siga o guia.
- **Quem já tem o app** (1.6.0 ou mais nova) não precisa fazer nada: ele confere esta página ao abrir, baixa a
  versão nova e a instala quando é fechado.

Aqui ficam só os pacotes, o guia de instalação e o `versao.json` que o app consulta.
